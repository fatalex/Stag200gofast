# STAG-200 GoFast — Android-приложение (Bluetooth SPP)

Нативное Android-приложение на Kotlin для подключения к газовому ЭБУ **STAG-200 GoFast** по классическому **Bluetooth (SPP/RFCOMM)** с реализацией протокола UGIC (извлечённого из `Stag200Easy.exe`).

## Как получить готовый файл `.apk` БЕЗ установки Android Studio (через GitHub за 3 минуты)
1. Зайдите на [github.com](https://github.com) и создайте новый репозиторий (например, `stag200-android`).
2. Распакуйте этот ZIP-архив и загрузите все файлы (включая скрытую папку `.github`) в репозиторий (кнопка **Add file → Upload files**).
3. Перейдите во вкладку **Actions** → выберите **Build Android APK** → нажмите **Run workflow** (или сборка запустится сама).
4. Через 2–3 минуты внизу страницы сборки появится артефакт **`STAG200GoFast-debug-apk`** — скачайте его, распакуйте и установите `app-debug.apk` на телефон Android.

## Как собрать в Android Studio (на ПК)
1. Распакуйте архив и откройте папку `Stag200GoFastAndroid` в Android Studio.
2. Дождитесь синхронизации Gradle и нажмите **Build → Build Bundle(s) / APK(s) → Build APK(s)**.

## Как пользоваться в машине
1. Спарьте Bluetooth-адаптер STAG в настройках Bluetooth Android (PIN обычно `1234` или `0000`).
2. Откройте приложение **STAG-200 GoFast**, нажмите **«Выбрать Bluetooth»** и выберите ваш адаптер.
3. Нажмите **«0x03 Связь»** и **«0x14 Live»** — если в поле **HEX-ЛОГ ОБМЕНА** появятся ответы `RX`/`RAW`, нажмите **«Копировать»** и пришлите лог для точной калибровки всех датчиков под вашу прошивку.
